### Pregunta 1 (2 puntos)
**Caso Práctico 1: El invernadero inteligente**

En un invernadero, se requiere mantener siempre la humedad perfecta para las plantas. Cuando el ambiente se seca, el sistema abre las válvulas de agua para regar de forma automática hasta que el suelo vuelve a estar húmedo.

**Enunciado:**  
Identifica el componente: Para saber si el ambiente está seco o húmedo, ¿qué elemento tecnológico se está utilizando en el suelo? (Elige entre sensor o actuador). Justifica tu respuesta.

<details class="quiz-option correct">
  <summary><strong>Ver respuesta</strong></summary>
  <div class="feedback">
    <div class="feedback-title">Respuesta:</div>
    Sensor, presumiblemente un sensor de humedad en el suelo. Se encargará de medir la humedad y, en base a ello, enviar una señal eléctrica al sistema que procesa los datos y envía la orden al actuador, que sería el que la ejecuta, hasta que el sensor detecta nuevamente que los niveles de humedad son los adecuados.
  </div>
</details>

### Pregunta 2 (3 puntos)
**Caso Práctico 2: El sistema de tráfico de Singapur**

El sistema de semáforos de Singapur ajusta las luces verdes y rojas en tiempo real. Si los componentes detectan que una calle está muy congestionada, el sistema decide dar más tiempo de luz verde a esa calle para evitar el atasco.

**Enunciado:**  
Identifica la capa del sistema: Cuando el sistema informático analiza los datos del tráfico y toma la decisión autónoma de cambiar las luces para solucionar el atasco, ¿en qué capa del sistema ciberfísico estamos? (Elige entre Capa de Transmisión o Capa de Aplicación). Justifica tu respuesta.

<details class="quiz-option correct">
  <summary><strong>Ver respuesta</strong></summary>
  <div class="feedback">
    <div class="feedback-title">Respuesta:</div>
    Capa de Aplicación, es la que se encarga de procesar y analizar los datos que llegan sobre el tráfico y, en base a ello, tomar la decisión de cambiar las luces del semáforo para evitar el atasco, la Capa de Transmisión solo se ocuparía de enviar esos datos por la red, no los analiza ni toma decisiones.
  </div>
</details>
