### Pregunta 1
¿Qué es un sistema operativo multiusuario?

<details class="quiz-option incorrect">
  <summary>A) Un sistema operativo multiusuario es aquel que permite que un solo usuario utilice el sistema en un momento dado.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Esta definición describe a un sistema monousuario, en el cual los recursos y las sesiones quedan restringidos a una única persona de manera exclusiva.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un sistema operativo multiusuario es aquel que permite que el sistema sea utilizado por usuarios de diferentes países.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La procedencia geográfica o el idioma de los usuarios no define la arquitectura interna de gestión de cuentas y sesiones del sistema operativo.
  </div>
</details>
<details class="quiz-option correct">
  <summary>C) Un sistema operativo multiusuario es aquel que permite que múltiples usuarios utilicen el sistema al mismo tiempo.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Un sistema multiusuario gestiona múltiples cuentas, sesiones independientes, permisos de acceso y asignación concurrente de memoria y procesamiento para varios usuarios simultáneamente.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Un sistema operativo multiusuario es aquel que permite que el sistema sea utilizado por usuarios de diferentes dispositivos.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    El acceso desde distintos dispositivos hace referencia a la conectividad en red o a la compatibilidad cliente-servidor, no al concepto intrínseco de concurrencia de usuarios del núcleo del sistema.
  </div>
</details>

### Pregunta 2
¿Qué es Windows?

<details class="quiz-option incorrect">
  <summary>A) Windows es un sistema operativo desarrollado por Apple.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Apple es la empresa responsable del desarrollo de sistemas operativos como macOS e iOS.
  </div>
</details>
<details class="quiz-option correct">
  <summary>B) Windows es un sistema operativo desarrollado por Microsoft.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Windows es la familia de sistemas operativos para entornos de escritorio, estaciones de trabajo y servidores desarrollada y comercializada por Microsoft desde 1985.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Windows es un sistema operativo desarrollado por Linux.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Linux es un núcleo (kernel) de código abierto iniciado por Linus Torvalds, no una empresa desarrolladora ni el origen de Windows.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Windows es un sistema operativo desarrollado por Google.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Google desarrolla plataformas como Android y ChromeOS, no la familia Windows.
  </div>
</details>

### Pregunta 3
¿Qué es un sistema operativo monotarea?

<details class="quiz-option incorrect">
  <summary>A) Un sistema operativo monotarea es aquel que permite la ejecución de múltiples programas a la vez.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La capacidad de ejecutar múltiples procesos o tareas concurrentes define a los sistemas multitarea.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un sistema operativo monotarea es aquel que permite la ejecución de programas en distintas ubicaciones geográficas.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La ejecución en distintos emplazamientos físicos describe sistemas distribuidos o en red, no el modo de gestión monoproceso del procesador.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Un sistema operativo monotarea es aquel que permite la ejecución de programas en distintos dispositivos.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Esta característica corresponde a la interoperabilidad entre plataformas o procesamiento distribuido.
  </div>
</details>
<details class="quiz-option correct">
  <summary>D) Un sistema operativo monotarea es aquel que permite la ejecución de un solo programa a la vez.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Un sistema monotarea (como el histórico MS-DOS) únicamente puede mantener un único proceso activo en memoria y CPU, requiriendo que la aplicación finalice antes de poder iniciar otra.
  </div>
</details>

### Pregunta 4
¿Qué es un sistema operativo?

<details class="quiz-option correct">
  <summary>A) Un sistema operativo es un conjunto de programas que permiten administrar los recursos de un ordenador.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    El sistema operativo actúa como software de base intermediario entre el hardware físico (procesador, memoria, almacenamiento, periféricos) y las aplicaciones de usuario, gestionando su asignación de forma eficiente y segura.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un sistema operativo es un dispositivo físico utilizado para almacenar y procesar información.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Los componentes físicos (discos duros, módulos de RAM o procesadores) corresponden a la categoría de hardware, no al software base.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Un sistema operativo es una aplicación que se encarga de realizar tareas específicas en un ordenador.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Los programas diseñados para tareas concretas (procesadores de texto, hojas de cálculo, navegadores) son software de aplicación, los cuales se ejecutan sobre el sistema operativo.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Un sistema operativo es una red de ordenadores interconectados que comparten recursos.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Un conjunto de ordenadores conectados para compartir recursos conforma una red informática (LAN, WAN), no el sistema operativo individual de una máquina.
  </div>
</details>

### Pregunta 5
¿Qué es un sistema operativo monousuario?

<details class="quiz-option incorrect">
  <summary>A) Un sistema operativo monousuario es aquel que permite que el sistema sea utilizado por usuarios de diferentes países.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La procedencia territorial de los usuarios no tiene relación con el modelo de concurrencia y control de sesiones del sistema operativo.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un sistema operativo monousuario es aquel que permite que el sistema sea utilizado por usuarios de diferentes dispositivos.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La capacidad de enlace con diversos dispositivos describe características de red y compatibilidad de periféricos.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Un sistema operativo monousuario es aquel que permite que múltiples usuarios utilicen el sistema al mismo tiempo.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Poder atender a varios usuarios con sesiones simultáneas es la función definitoria de los sistemas multiusuario.
  </div>
</details>
<details class="quiz-option correct">
  <summary>D) Un sistema operativo monousuario es aquel que permite que un solo usuario utilice el sistema en un momento dado.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Un sistema monousuario está diseñado para responder a las solicitudes de un único operador por sesión, sin contemplar la concurrencia simultánea de múltiples usuarios independientes en los recursos locales.
  </div>
</details>
