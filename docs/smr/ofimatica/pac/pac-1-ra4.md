### Pregunta 1
¿Cuál es la función principal de una base de datos?

<details class="quiz-option correct">
  <summary>A) Almacenar, organizar y gestionar grandes cantidades de información de manera eficiente.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    La finalidad de una base de datos (y de los SGBD) es centralizar el almacenamiento de datos evitando redundancias, garantizar su integridad y facilitar consultas y modificaciones rápidas y seguras.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Crear gráficos y analizar datos estadísticos.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Esta tarea es característica de herramientas de hoja de cálculo (como Excel o Calc) o suites de análisis de datos (como Power BI).
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Crear presentaciones y diapositivas interactivas.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Corresponde a programas ofimáticos de diseño de diapositivas (como PowerPoint o Impress).
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Editar y formatear documentos de texto.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Es la función esencial de los procesadores de textos (como Word o Writer).
  </div>
</details>

### Pregunta 2
¿Qué elemento identifica de forma única cada registro en una tabla?

<details class="quiz-option incorrect">
  <summary>A) Informe</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Un informe es un objeto destinado a dar formato, calcular e imprimir un resumen visual de los datos recopilados.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Consulta</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Una consulta es una instrucción o petición formal para recuperar, filtrar o modificar información almacenada en una o varias tablas.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Campo</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Un campo es una columna que define un atributo o tipo de dato concreto (por ejemplo, "Nombre" o "Teléfono"), pero por sí mismo puede contener valores repetidos.
  </div>
</details>
<details class="quiz-option correct">
  <summary>D) Clave primaria</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    La clave primaria (*Primary Key*) es un campo o combinación de campos cuyos valores no pueden repetirse ni ser nulos, garantizando la identificación exclusiva e inequívoca de cada fila (registro).
  </div>
</details>

### Pregunta 3
¿Qué es una tabla en una base de datos?

<details class="quiz-option incorrect">
  <summary>A) Un tipo de gráfico</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Los gráficos son representaciones visuales estadísticas de datos numéricos.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un archivo multimedia</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Los archivos multimedia almacenan audio, vídeo o imagen binaria.
  </div>
</details>
<details class="quiz-option correct">
  <summary>C) Un conjunto de registros organizados en filas y columnas</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    En el modelo relacional, la tabla (o relación) es la estructura base que organiza la información en filas (registros o tuplas) y columnas (campos o atributos).
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Un programa</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Una tabla es un componente estructural de almacenamiento de datos dentro del Sistema Gestor de Bases de Datos (SGBD), no un programa ejecutable independiente.
  </div>
</details>

### Pregunta 4
¿Qué es un registro?

<details class="quiz-option correct">
  <summary>A) Una fila que contiene datos relacionados</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Un registro (o tupla) representa una entidad u objeto individual dentro de la tabla (por ejemplo, todos los datos correspondientes a un alumno concreto agrupados en una fila horizontal).
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Un archivo multimedia</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    No define el concepto operativo fundamental de fila en bases de datos relacionales.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Un informe</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Un informe es una salida estructurada y maquetada de datos para su exportación o impresión.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>D) Una columna que almacena un tipo de dato específico</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    La columna que define una categoría o tipo de dato particular recibe el nombre de **campo** o atributo.
  </div>
</details>

### Pregunta 5
¿Qué es una base de datos?

<details class="quiz-option incorrect">
  <summary>A) Es una hoja de cálculo que permite realizar operaciones matemáticas y estadísticas.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Define aplicaciones analíticas de cuadrícula de celdas como Calc o Excel, las cuales tienen limitaciones de concurrencia y volumen frente a una base de datos.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>B) Es un programa informático utilizado para crear gráficos y presentaciones.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Corresponde a software de edición y diseño gráfico o presentaciones multimedia.
  </div>
</details>
<details class="quiz-option incorrect">
  <summary>C) Es un lenguaje de programación utilizado para el desarrollo web.</summary>
  <div class="feedback">
    <div class="feedback-title">✗ Incorrecto</div>
    Describe lenguajes de desarrollo como JavaScript, Python o PHP, no a una estructura de persistencia de datos.
  </div>
</details>
<details class="quiz-option correct">
  <summary>D) Es una colección organizada de información que se almacena de forma estructurada y se puede acceder y gestionar fácilmente.</summary>
  <div class="feedback">
    <div class="feedback-title">✓ ¡Exacto!</div>
    Una base de datos es un contenedor lógico estructurado diseñado para almacenar grandes conjuntos de información interrelacionada, permitiendo consultas simultáneas, control de concurrencia y consistencia de datos a través de un SGBD.
  </div>
</details>
