# Autoaprendizaje: Programación en Java

Ruta autodidacta orientada a afianzar la lógica de programación y la Programación Orientada a Objetos (POO) como preparación técnica para el ciclo de **DAM**.

* **Curso base:** [Java Programming I & II (mooc.fi)](https://java-programming.mooc.fi/) — Universidad de Helsinki.
* **Entorno de desarrollo:** NetBeans con plugin Test My Code (TMC) y JDK.
* **Repositorio de código:** [Beamspark/java-programming-mooc](https://github.com/Beamspark/java-programming-mooc)

---

## 🎯 Objetivos de la ruta
* Dominar la sintaxis estructurada y la gestión de flujos de entrada/salida.
* Comprender el uso de la memoria en Java (primitivos vs referencias).
* Implementar colecciones dinámicas (`ArrayList`) y algoritmos fundamentales.
* Desarrollar código modular y buenas prácticas de POO.
